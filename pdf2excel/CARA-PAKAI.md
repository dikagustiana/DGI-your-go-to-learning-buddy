# Cara Memakai "PDF ke Excel"

Aplikasi ini mengubah dokumen PDF hasil scan menjadi tabel Excel.
Semuanya diproses di komputer sendiri — **tidak perlu internet**, dan
dokumen **tidak dikirim ke mana-mana**.

---

## Memasang aplikasi (sekali saja)

1. Buka file **`PDF-ke-Excel-Setup.exe`** (dobel-klik).
2. Kalau muncul layar biru bertuliskan *"Windows protected your PC"*:
   klik tulisan kecil **More info**, lalu klik **Run anyway**.
   Ini hanya peringatan karena aplikasinya baru — aman.
3. Klik **Lanjut** terus sampai **Selesai**. Tidak perlu mengubah
   apa-apa.
4. Setelah itu ada gambar **PDF ke Excel** di layar utama (Desktop).
   Itu tombol untuk membuka aplikasinya.

---

## Mengubah PDF menjadi Excel (3 langkah)

1. **Dobel-klik gambar "PDF ke Excel"** di Desktop.

2. **Klik tombol biru "1. Buka file PDF"**, lalu pilih file PDF yang
   mau diubah, dan klik **Open**.
   Di bawah tombol akan tertulis nama filenya, misalnya:
   `✓ rekening koran.pdf — 156 halaman`.

3. **Klik tombol biru "2. Ubah ke Excel"**, lalu **tunggu**.
   Akan terlihat tulisan seperti:
   *"Sedang memproses halaman 12 dari 156… Mohon tunggu, ya."*
   Dokumen yang tebal bisa makan waktu lama (sekitar satu jam untuk
   150 halaman). Komputer boleh ditinggal, asal jangan dimatikan.

Kalau sudah selesai, muncul tulisan hijau:
**"Selesai! File Excel tersimpan di: …"**

* Klik **"Buka file Excel"** untuk langsung melihat hasilnya, atau
* Klik **"Buka foldernya"** untuk melihat tempat file itu disimpan.
  (File-nya ada di folder **Documents / Dokumen**, dengan nama yang
  sama seperti PDF-nya.)

Sudah. Itu saja.

---

## Kalau perlu berhenti di tengah jalan

Klik tombol merah **"Berhenti dulu"**. Halaman yang sudah selesai
tidak hilang. Lain kali, buka file PDF yang sama, jawab **Yes** waktu
ditanya *"Lanjutkan pekerjaan sebelumnya?"*, lalu klik
**"2. Ubah ke Excel"** lagi — aplikasi melanjutkan dari yang belum
selesai, tidak mengulang dari awal.

## Kalau muncul pesan kesalahan

Baca pesannya — di situ tertulis apa yang terjadi dan apa yang perlu
dilakukan. Contoh yang paling sering:

* *"File ini tidak bisa dibuka sebagai PDF"* → file yang dipilih bukan
  PDF; pilih file yang namanya berakhiran **.pdf**.
* *"File Excel-nya sepertinya sedang terbuka"* → tutup dulu jendela
  Excel, lalu coba lagi.

## Memeriksa hasil (tidak wajib)

Angka hasil pembacaan mesin sesekali bisa keliru. Kalau dokumennya
penting (laporan keuangan), minta yang biasa memegang komputer untuk
mengklik **"Periksa hasil (opsional)"** setelah selesai: di situ
gambar halaman dan tabelnya berdampingan, kotak **kuning** artinya
mesin kurang yakin, dan angka bisa langsung diperbaiki — perbaikan
otomatis tersimpan ke file Excel.
